# SwiftPharma WordPress Website

A WordPress website developed and customized for **SwiftPharma**. The project was deployed to the company server and is currently available as a live website.

## Live Website

[View SwiftPharma Website](https://spr.ikjimpex.com/)

## Project Overview

This project includes a responsive business website with WordPress-based content management. Authorized users can manage website content through the WordPress admin area, including adding, editing, and removing content/images where the relevant WordPress fields or sections are provided.

## Technologies

- WordPress
- PHP
- HTML5
- CSS3
- JavaScript
- Bootstrap
- MySQL / WordPress database
- WooCommerce support

## Main Work

- WordPress theme customization
- Responsive website implementation
- Business/product content sections
- Contact and content-related templates
- Front-end styling and JavaScript integration
- WordPress deployment to a live company server

## Repository Scope

This repository contains the project theme/source files used for the portfolio project. The WordPress database, `wp-config.php`, local development environment, uploads outside the theme, and server credentials are intentionally not included.

### Security note

Real SMTP credentials and client/server login information have been removed from this portfolio copy. The legacy mail-handler files contain placeholders that must be configured separately in a real deployment. Never commit passwords, API keys, tokens, database credentials, or server login details to a public repository.
